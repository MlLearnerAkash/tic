Everything in one popover

Stop juggling windows.

The three things you reach for all day, one click apart. Built to be read at a glance and driven from the keyboard.

Todos that land on the right day

Type, press Return, done. Today comes first, tomorrow is next, and anything overdue is called out in red.

  • Today, Tomorrow and future-day sections
  • Drag to reorder or move between days
  • Space completes, Return edits, ⌘D picks a date
  • A little confetti when you finish something

Clipboard history with a memory

Text, links, code, images and files — kept with the app they came from and when. Find it, preview it, copy it back.

  • Instant search across content and source app
  • Preview overlay with selectable text and images
  • Duplicate copies move to the top with a count
  • Passwords and concealed pasteboard data are skipped

A focus timer that leaves you alone

Pick 25, 50 or 90 minutes — or any length up to a day. The menu bar counts down while you work.

  • Do Not Disturb on and off through Shortcuts
  • Survives sleep, quitting and restarting
  • Soft chime when the time is up
  • No shortcut can end a session — only a confirmed click

Your data stays yours

No account, no sync server, no analytics and no network requests. Tic writes to one folder on this Mac.

~/Library/Application Support/Tic/
  • Export everything — images included — as one JSON file
  • Import only adds; it never overwrites what's there
  • Password managers and concealed copies are ignored
  • Source code is public and auditable

First launch

Tic is ad-hoc signed, not notarized. If macOS blocks it, right-click Tic in Applications and choose Open — or clear the quarantine flag:

xattr -d com.apple.quarantine /Applications/Tic.app

Good to know

Questions, answered.

Is Tic really free?

Yes. No trial, no subscription, no account. Download it, use it, and read the source if you like.

Why does macOS warn me on first launch?

Tic is ad-hoc signed rather than notarized by Apple, which requires a paid developer account. Right-click the app → Open once, or run the xattr command above. After that it launches normally.

Does it work on Intel Macs?

The current release is an Apple silicon build (arm64). On an Intel Mac you can build from source with swift build using the steps in the README.

How does the focus timer turn on Do Not Disturb?

macOS has no public API for toggling Focus. Tic runs two Shortcuts you create — “Tic Focus On” and “Tic Focus Off” — and only turns off a mode it turned on. You can rename them in Settings.

Does the clipboard record passwords?

No. Tic ignores pasteboard items marked concealed or private by password managers, and never records while a known password-manager app is frontmost. The list is deliberately conservative.

Where is my data stored?

In ~/Library/Application Support/Tic/ as JSON plus image files. There is no cloud component. Export and import live in Settings.

Can I build it myself?

Yes. The full SwiftUI source, build script and DMG packaging script are in the GitHub repository. It needs macOS 14+ and the Xcode Command Line Tools.
